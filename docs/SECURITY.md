# CherryLink — MySQL security architecture

- **Authentication:** MySQL user records with salted Node.js scrypt hashes; opaque 256-bit random session tokens stored hashed in MySQL and sent through HttpOnly, SameSite=Lax cookies. Secure flag enabled on HTTPS production. Login is rate-limited and failures do not reveal whether email exists. Mutations require a session-derived CSRF header.
- **Team roles:** Workspace ADMIN and EDITOR membership checked server-side on all privileged routes. No client-supplied workspace ID is trusted without authorization.
- **Invitations:** Short-lived, random, one-time invite link; only the SHA-256 token hash is persisted. Without email infrastructure the admin shares the link manually.
- **Meta credentials:** AES-256-GCM encrypted at rest with a separate 32-byte server-only secret. Neither Meta App Secret nor tokens are returned to the browser.
- **Media:** Private disk paths generated by the server, path traversal blocked by a strict allowlist. Media is served to Meta using HMAC-signed short-lived URLs; no access token appears in these URLs. Server-side MIME sniffing and FFprobe checks reject unsupported uploads.
- **Jobs:** MySQL InnoDB `FOR UPDATE SKIP LOCKED`, per-account leases, attempt logs, immutable PUBLISHED targets, and a quarantine state (`UNKNOWN`) prevent blind retries of uncertain publishing requests.
- **Database isolation:** A single API-owned MySQL credential is a privileged access path, so enforce strict API workspace authorization and use least-privilege MySQL accounts. There is no row-level security product feature.
- **Logging:** Never log password, session cookies, CSRF token, Meta access token or signing secrets. Reject cross-workspace resource IDs. Rotate keys and revoke sessions on suspected compromise.
- **Risks:** Do not enable live publishing until integration tests include access control, concurrent workers, Meta OAuth callbacks, media storage persistence and duplicate-prevention fault injection. Production must use HTTPS and a persistent shared media volume.
